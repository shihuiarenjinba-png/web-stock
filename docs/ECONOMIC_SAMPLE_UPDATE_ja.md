# DemandScope 公的経済変数サンプル更新

DemandScopeの追加説明変数として使う月次サンプルを、e-Statから定期更新します。

## 既定採用変数

- 消費者態度指数

各ファイルは `date + 数値変数1列` で、DemandScopeの追加変数入力形式に合わせます。
保存期間は最新120か月です。

## 候補だが既定除外

- コアCPI（生鮮食品を除く総合、前年同月比）
- 鉱工業生産前年比

CPIは商品別需要への効果が一方向・一般的に安定するとは限らず、鉱工業生産は一般消費財よりB2B/産業需要向けです。
そのため現在は `approved=false` とし、自動配布しません。

## 採用基準

変数は `config/estat_economic_samples.json` の `approved=true` のものだけ出力されます。
追加時には研究上の根拠、変換方法、採用理由を設定ファイルへ記録します。

DemandScopeでは次を満たす変数だけ既定採用します。

- 消費・需要との解釈が直接的
- 日本での実証または公的統計の明確な用途説明がある
- 月次で継続取得できる
- 120か月を欠損なくそろえられる
- 顧客データでの有意性を保証するような表示をしない

内閣府の消費動向調査は、消費者の意識や耐久消費財の買い時判断等を把握し、今後の消費動向をみるための統計です。
日本の研究でも、可処分所得をコントロールした後も消費者心理が消費支出へ影響する結果が報告されています。

## セキュリティ

GitHub Actionsではe-StatアプリケーションIDを Repository Secret `ESTAT_APP_ID` からのみ受け取ります。

- ブラウザ/CloudflareへAPIキーを配布しない
- URLやappIdをログへ出さない
- raw APIレスポンスを保存しない
- 公開するのは120か月へ整形したCSVとprovenanceのみ
- commit直前にSecret値混入チェックを実施

APIキーの登録方法は `docs/ESTAT_SECRET_SETUP_ja.md` を参照してください。

## 注意

このサンプルは月次履歴向けです。日次需要にそのまま同月値を展開すると、公表時点を無視した先読みになる可能性があるため、自動的な日次forward-fillは行いません。
研究で関係が示されていても、特定SKU・業種・期間で有意になることは保証しません。
